### Docker Task Manager
[Source](https://github.com/Pinfinity07/docker-task-manager)

A 3-tier task manager engineered for containerization and automated deployments. Built with multi-stage Docker builds using Nginx to serve Vite React assets, an Express API, and MySQL with persistent storage volumes. Database migrations run through a dedicated one-shot container before application boot. GitHub Actions CI provisions a MySQL service container, executes Knex migrations, and runs integration tests with Jest and Supertest. Deployed on an AWS EC2 instance with custom security group rules.

`Docker` `Docker Compose` `Nginx` `GitHub Actions` `AWS EC2` `Node.js` `Express` `MySQL` `Knex.js` `React` `Vite` `Jest` `Supertest`

### Vaultly: Collaborative Finance Tracker
[Live](https://vaultly-one.vercel.app/) · [Source](https://github.com/Pinfinity07/Vaultly)

Full-stack finance platform for tracking personal and group expenses, shared savings goals, and spending analytics. Uses JWT with Google OAuth 2.0 in httpOnly cookies, route-level rate limiting, role-based group permissions, and atomic database increments for concurrent contributions. GitHub Actions CI runs Jest and Supertest suites alongside Next.js lint and build checks. Deployed on Vercel, Render, and Neon PostgreSQL.

`Next.js` `React` `TypeScript` `Node.js` `Express` `PostgreSQL` `Prisma ORM` `Zustand` `Tailwind CSS` `JWT` `Google OAuth` `GitHub Actions`

### Vehicle Maintenance Predictor
[Live Demo](https://huggingface.co/spaces/kaori02/vehicle-maintenance-predictor) · [Source](https://github.com/Pinfinity07/vehicle-maintenance-predictor)

Machine learning pipeline to predict vehicle maintenance needs. Features modular Python scripts for data cleaning, SMOTE class balancing, and Decision Tree training with GridSearchCV optimization. Model artifacts are serialized with joblib for deterministic inference, paired with an interactive Gradio UI hosted on Hugging Face Spaces.

`Python` `scikit-learn` `Pandas` `SMOTE` `Gradio` `Hugging Face Spaces`
