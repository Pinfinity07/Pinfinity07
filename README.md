### Docker Task Manager — Production Containerized 3-Tier App & CI/CD Pipeline
[Source](https://github.com/Pinfinity07/docker-task-manager)

Full-stack task manager containerized end-to-end as a Docker learning and deployment project. Multi-stage Docker builds with Nginx serving the React frontend, production-hardened Express backend, and MySQL in a persistent volume. Separate Compose configs for dev and prod; database migrations run via a dedicated one-shot container before the API boots. GitHub Actions CI spins up a transient MySQL service container, runs Knex migrations, and executes the full Jest/Supertest integration suite. Deployed on an AWS EC2 instance with custom security groups.

`Docker` `Docker Compose` `Nginx` `GitHub Actions` `AWS EC2` `Node.js` `Express` `MySQL` `Knex.js` `React` `Vite` `Jest` `Supertest`

### Vaultly — Collaborative Finance Tracker
[Live](https://vaultly-one.vercel.app/) · [Source](https://github.com/Pinfinity07/Vaultly)

Full-stack finance platform for personal and shared group expenses, savings goals, and spending analytics. Dual auth (Email/Password + Google OAuth 2.0) with short-lived JWT access tokens and httpOnly cookie refresh, route-level rate limiting, RBAC for group management, and atomic Prisma increments for concurrent goal contributions. GitHub Actions CI runs Jest/Supertest backend tests and Next.js lint + build checks. Frontend on Vercel, API on Render, PostgreSQL on Neon.

`Next.js` `React` `TypeScript` `Node.js` `Express` `PostgreSQL` `Prisma ORM` `Zustand` `Tailwind CSS` `JWT` `Google OAuth` `GitHub Actions`

### Agentic Fleet Pipeline — ML Systems & Backend Pipeline
[Live Demo](https://huggingface.co/spaces/kaori02/vehicle-maintenance-predictor) · [Source](https://github.com/Pinfinity07/vehicle-maintenance-predictor)

Modular ML pipeline predicting vehicle maintenance requirements. Decoupled Python modules for data cleaning, SMOTE class balancing, and Decision Tree training optimized via GridSearchCV.
