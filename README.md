### [Vehicle Maintenance Predictor](https://github.com/Pinfinity07/vehicle-maintenance-predictor) — ML Pipeline
[![Live Demo](https://img.shields.io/badge/Live_Demo-FF9D00?style=flat-square&logo=huggingface)](https://huggingface.co/spaces/kaori02/vehicle-maintenance-predictor)
[![Report](https://img.shields.io/badge/Project_Report-4285F4?style=flat-square&logo=googledrive&logoColor=white)](https://drive.google.com/file/d/16fxy-LBw1LDIxirKwgz1W-qLFJUW7h1c/view?usp=sharing)

End-to-end ML pipeline that predicts whether a vehicle needs maintenance.

- **Pipeline**: Modular stages — data cleaning → feature engineering → model training
- **ML**: Decision Tree with GridSearchCV hyperparameter tuning (5-fold CV)
- **Imbalance**: SMOTE oversampling for handling class imbalance
- **Deployed**: Live Gradio web app on Hugging Face Spaces
- `Python` `scikit-learn` `SMOTE` `Gradio` `Pandas`
